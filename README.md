## Usarla nella suite

Impostazioni → Librerie → aggiungi libreria:

- URL base: `https://raw.githubusercontent.com/valentino-dell-eco/echo-library/main`
- Percorso indice: `search/index.json`

In alternativa, senza pubblicarla: Impostazioni → Contenuti locali → importa i file in `homebrew/split/`.

## Struttura

- `search/index.json` — indice di ricerca
- `data/` — dati nel layout del sito 5eTools
- `img/` — immagini nel layout 5etools-img
- `homebrew/KNUSC.json` — file homebrew unico (anche per il 5eTools ufficiale)
- `echo-library.json`, `_echo/` — progetto dell'app (non toccarli a mano)
